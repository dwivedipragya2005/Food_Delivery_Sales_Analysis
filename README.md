# Food Delivery Sales Analysis

## Project Overview

This project focuses on analyzing food delivery sales data using Python and Pandas. It covers the complete workflow from data inspection and cleaning to data preprocessing, statistical analysis, and extracting useful insights from sales data.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* SciPy
* Scikit-learn
* Jupyter Notebook
* CSV and Excel

## Work Completed

### 1. Data Import and Inspection

* Imported CSV datasets using Pandas
* Inspected rows, columns, and dataset structure
* Checked data types and statistical summaries

### 2. Data Cleaning

* Cleaned column names and removed extra spaces
* Checked for missing values and duplicate records
* Reviewed data types and data consistency

### 3. Data Preprocessing

* Prepared data for analysis
* Converted categorical data into numerical format using One-Hot Encoding
* Checked the preprocessed dataset for missing values

### 4. Data Filtering and Basic Analysis

* Filtered records using conditions
* Analyzed delivered orders
* Created calculated columns for sales analysis
* Calculated sales percentages and performed basic analysis using Pandas

### 5. Descriptive Statistical Analysis

* Calculated mean, median, and mode
* Analyzed variance, standard deviation, quartiles, and interquartile range (IQR)
* Checked skewness and potential outliers
* Examined covariance and correlation

### 6. Probability and Distributions

* Calculated the probability of delivered orders
* Explored normal distribution using a histogram
* Practiced binomial probability

### 7. Sampling and Confidence Intervals

* Practiced random sampling
* Explored the Central Limit Theorem through sample means
* Calculated a 95% confidence interval for average order value

### 8. Hypothesis Testing

* Performed a one-sample t-test
* Applied a chi-square test
* Practiced interpreting p-values and statistical significance

### 9. Correlation and Regression

* Examined the relationship between quantity and order value
* Created a scatter plot
* Built simple and multiple linear regression models
* Evaluated model performance using R² score

### 10. A/B Testing

* Compared order values for selected payment modes
* Applied a t-test to explore differences between group averages

### 11. Time Series Analysis

* Converted order dates into datetime format
* Analyzed monthly sales trends
* Calculated moving averages
* Practiced a simple next-month sales forecast

### 12. Grouping and Summary Reports

* Grouped sales by city, payment mode, and order status
* Calculated city-wise total sales and order counts
* Exported summary reports to CSV and Excel

## Files Included

* `Food_Delivery_Sales_Analysis.ipynb` — Jupyter Notebook containing the analysis
* `Food_Delivery_Sales.csv` — Original dataset
* `Food_Delivery_Sales_Cleaned.csv` — Cleaned dataset
* `Food_Delivery_Sales_Final.csv` — Final dataset
* `City_Sales_Summary.csv` — City-wise sales summary
* `City_Sales_Summary.xlsx` — City-wise sales summary in Excel format

## Key Learning Outcomes

* Practiced data cleaning and preprocessing using Pandas
* Learned statistical analysis and basic hypothesis testing
* Explored correlation, regression, and time series concepts
* Improved skills in data grouping, filtering, visualization, and reporting
* Learned to export analysis results to CSV and Excel files

## Note

This is a hands-on learning project built to practice Python-based data analytics. The dataset is small, so statistical tests, regression results, and forecasts are for learning purposes and should not be treated as reliable business predictions.
